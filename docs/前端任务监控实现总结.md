# 前端任务监控实现总结

## ✅ 已完成的功能

### 1. 核心 Hook - `useSummaryJob.ts`

**位置**: [apps/web/src/hooks/useSummaryJob.ts](apps/web/src/hooks/useSummaryJob.ts)

**功能**:
- 使用 React Query 实现任务状态轮询
- 每 2 秒自动查询任务进度
- 任务完成或失败时自动停止轮询
- 支持启用/禁用控制

**关键特性**:
```typescript
refetchInterval: (data) => {
  const status = data.data.status;
  // 正在进行: 每2秒轮询
  if (['pending', 'fetching', 'summarizing'].includes(status)) {
    return 2000;
  }
  // 已完成/失败: 停止轮询
  return false;
}
```

### 2. 任务进度弹窗 - `TaskProgressModal.tsx`

**位置**: [apps/web/src/components/TaskProgressModal.tsx](apps/web/src/components/TaskProgressModal.tsx)

**功能**:
- 实时显示任务进度（0-100%）
- 显示当前状态（等待、拉取中、AI生成中、完成、失败）
- 显示已拉取的消息数量
- 显示任务耗时（分钟+秒）
- 暗黑模式支持

**状态显示**:
- 🟡 **pending**: "等待开始..."
- 🔵 **fetching**: "正在拉取消息... (X 条)"
- 🟣 **summarizing**: "AI 生成中..."
- ✅ **completed**: "摘要已生成成功！"
- ❌ **failed**: "生成失败 - 原因: XXX"

**操作按钮**:
- 进行中: "后台运行" - 可以关闭弹窗，任务继续执行
- 完成: "查看摘要" - 关闭弹窗并刷新群组列表
- 失败: "关闭" - 关闭弹窗

## 🔄 完整的数据流

```
用户点击"生成总结"
    ↓
POST /api/summaries/generate
    ↓
创建任务记录 (summary_jobs 表)
    ↓
立即返回 202 + jobId
    ↓
前端开始轮询 GET /api/summaries/jobs/:id
    ↓
后端异步执行:
  1. 更新状态: fetching
  2. 拉取 Telegram 消息（激进自适应限流）
  3. 更新状态: summarizing
  4. AI 生成摘要
  5. 更新状态: completed
    ↓
前端检测到 completed
    ↓
停止轮询 + 刷新群组列表
```
