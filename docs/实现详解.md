# Omniknight 系统实现详解

## 概述

Omniknight 是一个 Telegram 群组 AI 总结系统,自动监听群组消息并使用 AI 生成高质量的结构化总结。本文详细讲解系统的技术实现和核心执行流程。

### 2. 消息拉取与限流

**位置**: [apps/backend/src/services/telegram/message-fetcher.ts](apps/backend/src/services/telegram/message-fetcher.ts)

#### 自适应限流策略

系统使用**激进自适应限流**策略,在保证不被封禁的前提下最大化拉取速度:

```typescript
class AdaptiveRateLimiter {
  private currentDelay = 200;      // 初始延迟 200ms
  private minDelay = 100;          // 最小延迟 100ms
  private maxDelay = 10000;        // 最大延迟 10s
  private consecutiveSuccess = 0;   // 连续成功次数

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    // 1. 等待延迟
    await sleep(this.currentDelay);

    try {
      // 2. 执行请求
      const result = await fn();

      // 3. 成功: 逐步降低延迟
      this.consecutiveSuccess++;
      if (this.consecutiveSuccess >= 3) {
        this.currentDelay = Math.max(
          this.minDelay,
          this.currentDelay * 0.9 // 降低10%
        );
      }

      return result;
    } catch (error) {
      // 4. FloodWait错误: 立即休眠指定时间
      if (error.errorMessage === 'FLOOD_WAIT') {
        const waitSeconds = error.seconds;
        await sleep(waitSeconds * 1000);
        return this.execute(fn); // 重试
      }

      // 5. 其他错误: 增加延迟
      this.currentDelay = Math.min(
        this.maxDelay,
        this.currentDelay * 2 // 翻倍
      );
      throw error;
    }
  }
}
```

**限流特性:**
- ✅ 初始200ms延迟,快速拉取
- ✅ 连续成功3次后降低10%延迟
- ✅ FloodWait错误自动休眠并重试
- ✅ 其他错误延迟翻倍
- ✅ 动态调整,最大化速度

#### 消息拉取流程

```typescript
async fetchMessagesWithRateLimit(
  client: TelegramClient,
  telegramId: string,
  periodStart: Date,
  periodEnd: Date,
  onProgress?: (update) => Promise<void>,
  topicId?: number
) {
  const limiter = new AdaptiveRateLimiter();
  const allMessages = [];
  let offsetId = 0;

  while (true) {
    // 1. 限流执行拉取
    const messages = await limiter.execute(() =>
      client.getMessages(telegramId, {
        limit: 100,
        offsetId,
        ...(topicId && { replyTo: topicId }), // Forum Topic支持
      })
    );

    // 2. 过滤时间范围
    const inRange = messages.filter(
      (msg) => msg.date >= periodStart && msg.date <= periodEnd
    );

    allMessages.push(...inRange);

    // 3. 报告进度
    if (onProgress) {
      await onProgress({
        progress: 50, // 拉取阶段占50%
        fetchedCount: allMessages.length,
      });
    }

    // 4. 检查是否结束
    if (messages.length < 100) break; // 没有更多消息
    if (messages[messages.length - 1].date < periodStart) break; // 超出时间范围

    offsetId = messages[messages.length - 1].id;
  }

  return allMessages;
}
```

**拉取特性:**
- 每批100条消息
- 自动过滤时间范围
- 支持Forum Topic
- 实时报告进度
- 自动重试FloodWait错误

```typescript
function shouldFilterMessage(message: Message): FilterResult {
  const text = message.text || '';

  // 1. 过滤短消息 (< 5字符)
  if (text.length < 5) {
    return { filtered: true, reason: '消息过短' };
  }

  // 2. 过滤纯表情消息
  if (/^[\u{1F600}-\u{1F64F}]+$/u.test(text)) {
    return { filtered: true, reason: '纯表情消息' };
  }

  // 3. 过滤纯媒体无文本
  if (!text && message.media) {
    return { filtered: true, reason: '仅媒体无文本' };
  }

  // 4. 过滤垃圾关键词
  const spamKeywords = ['广告', '加微信', '代办', '出售'];
  if (spamKeywords.some((kw) => text.includes(kw))) {
    return { filtered: true, reason: '包含垃圾关键词' };
  }

  return { filtered: false };
}
```

#### 完整生成流程

```typescript
async function generateSummary(
  groupId: number,
  periodStart: Date,
  periodEnd: Date,
  onProgress?: (update) => Promise<void>
) {
  // 1. 获取群组信息
  const group = await db.query.groups.findFirst({
    where: eq(groups.id, groupId),
  });

  // 2. 获取Telegram客户端
  const client = telegramService.getClient();

  // 3. 拉取消息 (带限流保护)
  logger.info('开始拉取消息', { groupId, period: '...' });
  const fetchedMessages = await fetchMessagesWithRateLimit(
    client,
    group.telegramId,
    periodStart,
    periodEnd,
    onProgress,
    group.topicId
  );

  // 4. 过滤无效消息
  const validMessages = fetchedMessages.filter(msg => !msg.isFiltered);
  logger.info('消息拉取完成', {
    fetchedCount: fetchedMessages.length,
    validCount: validMessages.length,
  });

  // 5. 检查消息数量阈值
  if (validMessages.length < group.minMessagesForSummary) {
    logger.warn('消息数量不足，跳过总结', {
      messageCount: validMessages.length,
      threshold: group.minMessagesForSummary,
    });
    return null;
  }

  // 6. 构建Prompt
  const userPrompt = buildSummaryPrompt(
    group,
    validMessages,
    periodStart,
    periodEnd
  );

  // 7. 调用AI生成
  logger.info('开始AI生成', { messageCount: validMessages.length });
  const aiResponse = await generateCompletion({
    messages: [
      { role: 'system', content: SYSTEM_PROMPT },
      { role: 'user', content: userPrompt },
    ],
    temperature: 0.7,
  });

  // 8. 提取标题
  const title = extractTitle(aiResponse.content) || '群组总结';

  // 9. 保存到数据库
  const [summary] = await db.insert(summaries).values({
    groupId,
    periodStart,
    periodEnd,
    content: aiResponse.content,
    title,
    messageCount: validMessages.length,
    aiModel: aiResponse.model,
    tokensUsed: aiResponse.tokensUsed,
    status: 'completed',
  }).returning();

  // 10. 更新群组最后总结时间
  await db.update(groups)
    .set({ lastSummaryAt: new Date() })
    .where(eq(groups.id, groupId));

  logger.info('总结生成成功', {
    summaryId: summary.id,
    title,
    tokensUsed: aiResponse.tokensUsed,
  });

  return summary;
}
```

**位置**: [apps/backend/src/services/scheduler/scheduler.ts](apps/backend/src/services/scheduler/scheduler.ts)

#### 调度流程

```typescript
class SchedulerService {
  private checkInterval = 60 * 1000; // 每分钟检查一次

  async start() {
    logger.info('📅 定时调度器启动');

    // 1. 立即执行一次检查
    await this.checkAndSchedule();

    // 2. 定期检查
    setInterval(async () => {
      await this.checkAndSchedule();
    }, this.checkInterval);
  }

  private async checkAndSchedule() {
    // 1. 获取所有启用的群组
    const activeGroups = await db.query.groups.findMany({
      where: eq(groups.isActive, true),
    });

    // 2. 检查每个群组
    for (const group of activeGroups) {
      await this.checkGroupSchedule(group);
    }
  }

  private async checkGroupSchedule(group) {
    // 1. 检查是否启用摘要
    if (!group.summaryEnabled) return;

    // 2. 计算是否到达间隔时间
    const now = new Date();
    const lastSummaryAt = new Date(group.lastSummaryAt);
    const intervalMs = group.summaryInterval * 60 * 60 * 1000;
    const shouldGenerate = now - lastSummaryAt >= intervalMs;

    if (shouldGenerate) {
      logger.info('🔔 触发定时摘要任务', {
        groupId: group.id,
        interval: `${group.summaryInterval}小时`,
      });

      // 3. 创建任务
      const job = await createSummaryJob(
        group.id,
        lastSummaryAt,
        now,
        'scheduled'
      );

      // 4. 异步执行
      executeSummaryJob(job.id).catch(err => {
        logger.error('定时任务执行失败', err);
      });

      // 5. 更新最后摘要时间
      await db.update(groups)
        .set({ lastSummaryAt: now })
        .where(eq(groups.id, group.id));
    }
  }
}
```

**调度特性:**
- ✅ 每分钟检查一次
- ✅ 支持自定义间隔 (小时)
- ✅ 异步执行,不阻塞检查
- ✅ 自动更新最后摘要时间

```typescript
async function executeSummaryJob(jobId: number) {
  const job = await getJob(jobId);

  try {
    // 1. 更新状态: fetching
    await updateJobStatus(jobId, 'fetching', 0);
    logger.info('开始拉取消息', { jobId });

    // 2. 执行总结生成 (带进度回调)
    const summary = await generateSummary(
      job.groupId,
      job.periodStart,
      job.periodEnd,
      async (update) => {
        // 实时更新进度
        await updateJobProgress(jobId, update.progress, update.fetchedCount);
      }
    );

    // 3. 更新状态: summarizing
    await updateJobStatus(jobId, 'summarizing', 50);
    logger.info('开始AI生成', { jobId });

    // 4. 更新状态: completed
    await updateJobStatus(jobId, 'completed', 100, summary.id);
    logger.info('任务完成', { jobId, summaryId: summary.id });

  } catch (error) {
    // 5. 错误处理
    logger.error('任务执行失败', { jobId, error });
    await updateJobStatus(jobId, 'failed', job.progress, null, error.message);
  }
}
```

```typescript
      {isInProgress && <button onClick={onClose}>后台运行</button>}

      {isFailed && <button onClick={onClose}>关闭</button>}
    </div>
  );
}
```

#### 3. 用户操作流程

```
用户点击"生成总结"
    ↓
调用 POST /api/summaries/generate
    ↓
获取 jobId
    ↓
开始轮询 GET /api/summaries/jobs/:id (每2秒)
    ↓
弹出进度窗口
    ↓
实时显示:
  - pending: "⏳ 等待开始..."
  - fetching: "🔄 正在拉取消息... (1523 条)"
  - summarizing: "🤖 AI 生成中..."
  - completed: "✅ 摘要已生成成功！"
    ↓
任务完成后停止轮询
    ↓
刷新群组列表,显示最新摘要数量
```

## 数据库设计

### 核心表结构

#### 1. groups (群组表)

```sql
CREATE TABLE groups (
  id INTEGER PRIMARY KEY,
  telegram_id TEXT NOT NULL UNIQUE,
  title TEXT NOT NULL,
  username TEXT,
  type TEXT NOT NULL,              -- group | channel | supergroup | forum
  topic_id INTEGER,                -- Forum Topic ID
  is_active BOOLEAN DEFAULT true,
  summary_enabled BOOLEAN DEFAULT true,
  summary_interval INTEGER DEFAULT 6,  -- 小时
  min_messages_for_summary INTEGER DEFAULT 20,
  last_summary_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 2. summaries (总结表)

```sql
CREATE TABLE summaries (
  id INTEGER PRIMARY KEY,
  group_id INTEGER NOT NULL REFERENCES groups(id),
  period_start TIMESTAMP NOT NULL,
  period_end TIMESTAMP NOT NULL,
  title TEXT,
  content TEXT NOT NULL,           -- Markdown格式
  message_count INTEGER,
  fetched_message_count INTEGER,
  ai_model TEXT,
  tokens_used INTEGER,
  generation_time INTEGER,         -- 毫秒
  status TEXT DEFAULT 'completed',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 3. summary_jobs (任务表)

```sql
CREATE TABLE summary_jobs (
  id INTEGER PRIMARY KEY,
  group_id INTEGER NOT NULL REFERENCES groups(id),
  period_start TIMESTAMP NOT NULL,
  period_end TIMESTAMP NOT NULL,
  status TEXT NOT NULL,            -- pending | fetching | summarizing | completed | failed
  progress INTEGER DEFAULT 0,      -- 0-100
  fetched_count INTEGER DEFAULT 0,
  triggered_by TEXT NOT NULL,      -- manual | scheduled
  scheduled_at TIMESTAMP NOT NULL,
  started_at TIMESTAMP,
  completed_at TIMESTAMP,
  failed_at TIMESTAMP,
  error_message TEXT,
  summary_id INTEGER REFERENCES summaries(id)
);
```

```sql
CREATE TABLE system_config (
  key TEXT PRIMARY KEY,
```

## 常见问题排查

### 1. Telegram认证失败

**症状:** 无法连接Telegram

**排查步骤:**
1. 检查 `TELEGRAM_API_ID` 和 `TELEGRAM_API_HASH` 是否正确
2. 检查手机号格式 (需要国家码, 如 +86)
3. 查看后端日志: `[ERROR] Telegram 认证错误`
4. 删除session重新认证: 数据库中删除 `telegram_session` 记录

### 2. 消息拉取失败

**症状:** FloodWait错误频繁

**排查步骤:**
1. 检查限流器配置
2. 增加初始延迟: `currentDelay = 500`
3. 检查是否多个实例同时拉取
4. 查看日志: `[WARN] FloodWait detected`

### 3. AI生成失败

**症状:** 总结生成失败

**排查步骤:**
1. 检查 `AI_API_KEY` 是否正确
2. 检查 `AI_API_BASE_URL` 是否正确
3. 检查API余额
4. 查看日志: `[ERROR] AI生成失败`
5. 尝试切换到Mock Provider测试

### 4. 定时任务不执行

**症状:** 自动总结不生成

**排查步骤:**
1. 检查群组 `summaryEnabled` 是否为 `true`
2. 检查 `summaryInterval` 配置
3. 检查 `lastSummaryAt` 时间
4. 查看日志: `[INFO] 📅 定时调度器启动`
5. 手动触发测试
